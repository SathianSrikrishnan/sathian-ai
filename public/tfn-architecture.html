Pillar 2

The Smart Contract

The rules engine. Non-custodial escrow that holds funds, enforces time-locks, and collects fees. No human controls the lockboxes — only code.

Anchor / Rust

Core Instructions (8)

  • initialize_child — Create child profile (guardian)
  • create_milestone — Record a lost tooth (guardian)
  • deposit — Send SOL with time-lock (anyone)
  • claim_deposit — Release matured funds (guardian)
  • early_withdraw — Break lock, 10% penalty (guardian)
  • refund_deposit — 7-day refund window (depositor)
  • transfer_guardianship — Change parent (guardian)
  • withdraw_treasury — Claim fees (admin)

On-Chain Accounts (PDAs)

  • Config — Global pause/unpause switch
  • Treasury — Accumulated platform fees
  • ChildProfile — One per child (max 20 milestones)
  • Milestone — One per tooth (tracks deposits)
  • Deposit — One per depositor per tooth (the vault)

Access Control

  • Anyone can deposit (family, friends)
  • Guardian controls claims + child profile
  • Admin can pause contract + withdraw fees
  • Original depositor can refund (7 days)
  • No single party can steal funds

Safety Features

  • Emergency pause (admin)
  • Time-lock enforcement (code, not humans)
  • Anti-spam minimum deposit (0.00001 SOL)
  • Max 20 milestones per child (20 baby teeth)
  • 7-day refund grace period
  • Guardianship transfer (divorce, custody)

Pillar 3

The Ledger

The permanent record. Solana blockchain stores every milestone and deposit. Arweave stores the art forever.

Solana Mainnet

Compressed NFTs (cNFTs)

  • Metaplex Bubblegum protocol
  • Merkle tree: 16,384 capacity
  • Cost: ~$0.001 per mint (vs $2+ regular NFT)
  • Displays in Phantom, Solflare, etc.
  • Child owns the NFT in their wallet

Permanent Storage (Arweave)

  • Tooth art uploaded via Irys
  • 200+ year storage guarantee
  • Immutable — no one can delete
  • Metadata JSON + image file

Infrastructure

  • RPC: Helius (mainnet, DAS API)
  • Tx cost: ~$0.005 per deposit
  • Finality: ~400ms
  • Server wallet: Signs mints + deposits
  • Deploy wallet: Program upgrades

Revenue Model
2%

Deposit Fee

Taken on every deposit, sent to Treasury PDA immediately. Non-refundable even if depositor requests refund within 7 days.

10%

Early Withdrawal Penalty

If guardian breaks a time-lock before maturity. 10% goes to Treasury, 90% goes to child. Incentivizes long-term saving.

7 days

Refund Grace Period

Original depositor can reclaim funds within 7 days. 2% fee is NOT returned. Prevents abuse while allowing mistakes.
