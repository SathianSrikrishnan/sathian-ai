# Colosseum Frontier 2026 Media Folder

Drop project-bound video assets here so Remotion can read them with `staticFile()`.

Folders:

- `captures/` - browser recordings, proof clips, screenshots.
- `avatar/` - Tanda talking-avatar stills and clips.
- `audio/` - founder soundbites, narration, music stems.
- `exports/` - rendered storyboard and final outputs.
