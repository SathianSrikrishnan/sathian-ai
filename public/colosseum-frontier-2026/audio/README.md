# Colosseum Audio Folder

Put recording and generated voice files here.

- `raw/` - Sathian raw recordings and scratch reads.
- `processed/` - cleaned final clips for editing.
- `elevenlabs/` - generated Tanda or narrator MP3 exports.

Use filenames from `src/remotion/colosseum/voiceover.ts` or the `/toothfairy/colosseum` production hub.
