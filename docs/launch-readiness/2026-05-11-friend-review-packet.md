# Tooth Fairy Network Friend Review Packet

Use this for the small review group before the Colosseum submission.

## Start Here

Primary path:
https://toothfairy.network/toothfairy

Use a real Gmail account so the Google recovery and dashboard path can be tested.

## What To Try

- Open the homepage on mobile first, then desktop if you have time.
- Read enough of the first story surface to understand what the product is.
- Start a Toothlight memory.
- Draw something simple.
- Try one Magic Studio AI polish result.
- Also try the original drawing fallback.
- Save the memory.
- Open the public keepsake link.
- Return through Google and check the dashboard.
- Share any point where you felt confused, worried, bored, or delighted.

## What Not To Do

- Do not send real SOL unless Sathian explicitly asks you to test the wallet path.
- Do not treat card gifts as live. Card gifts are paused.
- Do not stress-test with repeated AI generations. Each Gmail account has only 3 starter credits.

## What Feedback Helps Most

- Screenshot of the issue.
- Device and browser.
- Approximate step where it happened.
- Whether the product felt clear to a parent who is not crypto-native.
- Whether the story layer made the memory feel more meaningful.
- Whether the money/Smile Fund language felt safe and understandable.

## Current Launch Truth

The memory path is the main test. The wallet gift path is controlled testing. Card gifts wait until provider approval, payment verification, receipts, fee language, refunds, and support are ready.
