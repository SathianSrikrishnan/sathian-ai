## Safe update lanes

Normal weekly work may:

- add or revise a building log;
- add one reviewed article and its approved image;
- update a project status, proof link, or next milestone;
- refresh reviewed public-memory cards;
- add or retire a time-bounded campaign block;
- propose small copy changes inside an existing section.

Normal weekly work must not automatically:

- redesign the homepage;
- change the global type or colour system;
- reorder major sections;
- publish a draft;
- deploy to production;
- connect private memory or new tools to the public agent.

## Change request format

Future agents should describe a website change in five lines:

1. Surface being changed.
2. Reason the change matters.
3. Files or Studio records affected.
4. What remains untouched.
5. Proof required before review.
